# sites/

Static marketing sites that live next to the app but are **not part of it**. No build step, no npm dependencies, not included in the Vite build, `tsc` (`tsconfig.app.json` only includes `src`) or the app's tests.

## miketokovic/ — Tokovic LLC (https://miketokovic.com)

Plain HTML + CSS + vanilla JS, served as-is from `sites/miketokovic/`.

```
sites/miketokovic/
  index.html  404.html  privacy.html
  _headers  robots.txt  sitemap.xml  site.webmanifest
  assets/css/site.css  assets/js/main.js
  assets/img/logo.svg  favicon.svg  og.png (1200x630)
```

### Preview locally

```sh
cd sites/miketokovic && python3 -m http.server 4173   # http://localhost:4173
```

### Deploy (Cloudflare)

The site is a folder of static files, so any Cloudflare static hosting works.

- **Workers static assets** (config already in `sites/wrangler.jsonc`, serves `./miketokovic`, uses `404.html` for unknown paths):
  ```sh
  cd sites && npx wrangler deploy
  ```
  The `custom_domain` routes for `miketokovic.com` and `www.miketokovic.com` need any existing apex/www DNS records for those names removed first.
- **Cloudflare Pages** (alternative): framework preset none, build command empty, build output directory `sites/miketokovic`, then add the custom domain.

Both read `_headers` (security headers, long cache for `/assets/*`) and serve `404.html` automatically.

### Things to know

- **Cache busting.** `/assets/*` is cached for a year with `immutable`, and files are not fingerprinted. When you change any CSS, JS or image, bump the `?v=` query string on the `site.css` / `main.js` references in all three HTML pages (`?v=1` today).
- **Clean URLs.** Cloudflare redirects `/privacy.html` to `/privacy`. Canonical and sitemap therefore use `/privacy`; the on-page links keep `.html` so the site also works from a plain local server.
- **Fonts.** Geist and Geist Mono load from Google Fonts (the only external resource). The privacy notice says so. To remove the third-party request, self-host the two woff2 files under `assets/fonts/` and replace the `<link>` in each page with `@font-face` rules.
- **Email.** `office@miketokovic.com` is the only contact address on the site. Make sure the mailbox or a Cloudflare Email Routing rule exists before launch.
- **`og.png`** is a rendered composition (flow field, logo, tagline), palette-quantised to about 230 KB so chat apps show it. It is not generated by anything in the repo; re-render it if the tagline or brand changes.
- **Motion.** Everything honours `prefers-reduced-motion` and the page is fully readable without JavaScript. Content never depends on an animation finishing.
- **Content rules.** No endorsements, client logos, invented metrics or personal contact details. The only numbers on the page are the fitbyivana engineering stats supplied by the owner. Keep it that way.
